# IndiFit release identity assets

The public V1 icon uses a deep-midnight (`#060A12`) field and an
emerald/teal (`#34D399` / `#5EEAD4`) strength-and-growth emblem. The master is
opaque for iOS and legacy launcher surfaces. The adaptive foreground preserves
alpha for Android masks and launch screens.

The two masters were created with Codex's built-in image-generation tool on
2026-08-30. Platform-specific raster sizes are mechanical derivatives of these
source assets; they should be regenerated from the masters rather than edited
individually.

- `indifit_app_icon_master.png`: opaque 1024 × 1024 store/legacy master.
- `indifit_adaptive_foreground.png`: transparent 1024 × 1024 foreground master.

Generation prompt summary: a premium, centered geometric IndiFit emblem that
combines balanced strength bars with a rising leaf/energy form, using large
high-contrast shapes and generous adaptive-mask safe margins; no text, literal
fitness/food objects, border, device mockup, or watermark.
